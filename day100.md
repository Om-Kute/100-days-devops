🐚 4. Shell Scripting & Automation

Shell scripting reduces repetitive manual work.

Concepts learned

Variables

User input

Conditions

Loops

Functions

Exit codes

Command-line arguments

Scheduling with cron

Logging and error handling
Example script

#!/bin/bash

set -euo pipefail

LOG_FILE="/tmp/system-check.log"

{
    echo "System Check: $(date)"
    echo "Hostname: $(hostname)"
    echo "Uptime:"
    uptime
    echo "Disk Usage:"
    df -h
    echo "Memory Usage:"
    free -h
} | tee -a "$LOG_FILE"

Run the script:

chmod +x system-check.sh
./system-check.sh

Key takeaway

Automation scripts improve consistency and reduce repetitive operational tasks.
