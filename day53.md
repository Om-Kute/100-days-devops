## 📄 What is a Dockerfile?

A Dockerfile is a text file containing instructions used by Docker to automatically build a container image.

Think of it as a **recipe for creating a Docker image**.

```text
Dockerfile
     ↓
docker build
     ↓
Docker Image
     ↓
docker run
     ↓
Container
